**DIABOLIC LATAM** es una herramienta OSINT pasiva y analítica diseñada para monitorizar automáticamente **más de 120 fuentes de información de 26 países latinoamericanos**, extrayendo y procesando noticias de sucesos, análisis y alertas oficiales para detectar patrones delictivos, tendencias geográficas y conexiones entre incidentes, con especial énfasis en **narcotráfico, crimen organizado, violencia armada, finanzas ilícitas y corrupción**.

No guarda datos personales, solo titulares, fechas, ubicación aproximada (ciudad, estado/departamento o país) y tipo de delito. Filosofía: *"Un gran poder conlleva una gran responsabilidad"*.

## 🔍 ¿Qué hace DIABOLIC?

DIABOLIC automatiza el proceso de **scraping de noticias de sucesos, análisis y alertas oficiales** de medios y organismos de toda América Latina. En lugar de leer docenas de fuentes cada día, la herramienta:

- **Extrae** automáticamente titulares, fechas, fuentes y ubicación geográfica (ciudad, estado/departamento o país) de noticias relacionadas con delitos y crimen organizado.
- **Clasifica** los incidentes en tipos (narcotráfico, sicariato, masacre, balacera, extorsión, secuestro, desaparición, lavado, corrupción, etc.) con un motor anti-falsos-positivos que distingue usos criminales de usos cotidianos.
- **Geolocaliza** cada evento en cascada: ciudad → estado/departamento → país, siempre dentro del bbox del país.
- **Fusiona** varias fuentes que cubren el mismo hecho y aumenta la confianza del evento.
- **Almacena** los datos localmente en JSON, sin guardar ningún dato personal.
- **Analiza** tendencias temporales (7, 30, 90 días), patrones por país y tipo, y conexiones entre incidentes.
- **Detecta violencia armada** y dispara una alarma sonora y visual cuando aparece un conflicto, una masacre o un cluster de al menos 3 hechos de calle en 24 h en el mismo país.
- **Recolecta alertas oficiales** (DEA, OFAC, UNODC, fiscalías, policías, UIF, GAFILAT…) en un canal separado del resto de noticias.
- **Visualiza** los resultados en un panel web interactivo con mapa enriquecido y múltiples gráficos.
- **Exporta** los datos a JSON, CSV, HTML o GeoJSON.

## ⚙️ Características clave

### 🔁 Rotación de User-Agent
Lista de ~120 user-agents reales (Chrome, Firefox, Safari, Edge, Opera, Android, iOS, bots declarados) con rotación aleatoria por petición.

### 🧠 Paginación inteligente
Prueba automáticamente hasta 4 patrones de paginación (`/page/2/`, `?page=2`, `/pagina/2`, `?p=2`), detecta páginas repetidas por hash MD5 del HTML y corta si no hay contenido nuevo.

### 🔎 Detector automático de URLs
Si una URL deja de funcionar, el motor prueba variantes (`www`/sin `www`, con/sin barra), inspecciona la portada puntuando enlaces por palabras clave, y recurre a rutas clásicas (`/policiales`, `/sucesos`, `/noticias`, `/alertas`…). También detecta el RSS de la página.

### 📊 Clasificación avanzada de delitos
Lista amplia de tipos con regex fuertes y débiles, en español y portugués, incluyendo jerga regional (México, Colombia, Argentina, Brasil). Cada tipo tiene icono, color, categoría, severidad base y peso.

### 🔗 Conexiones entre incidentes
- **Por tipo y país** en los últimos 30 días.
- **Por modus operandi** (detección de términos como `sicariato`, `halcón`, `pitufeo`, `vuelco`).
- **Por frecuencia temporal** (incidentes/día).
- **Multi-fuente** (eventos confirmados por ≥2 medios).

### 🌐 Interfaz web interactiva
- 7 pestañas: Dashboard, Mapa, Gráficos, Red, Estáticos, Feed, Scan/Sources.
- Filtros por período, categoría, tipo, búsqueda textual y confianza mínima.
- Botones de scan (global, narco+violencia, finanzas, oficial), verificación, stop, mute, pantalla completa, copiar enlace y reset.
- Alertas oficiales en barra superior con nivel de "alerta regional" configurable.

### 🖥️ Menú terminal completo
20 opciones que permiten ejecutar todas las funciones sin abrir el navegador, incluido diagnóstico detallado por fuente.

## 🛠️ Tecnología y arquitectura

- **Lenguaje**: Python 3.8+
- **Framework web**: Flask
- **Scraping**: Requests + BeautifulSoup4
- **Almacenamiento**: JSON local (sin bases de datos externas)
- **Frontend**: Leaflet, Chart.js, vis-network (vía CDN)
- **Opcionales**: matplotlib, networkx (gráficos estáticos y red)

**Estructura lógica** (un único archivo):
- `URLAutoDiscoverer`: verifica y corrige URLs de fuentes.
- `VerificadorFuentes`: comprueba todas las fuentes y repara URLs caídas.
- `ExtractorNoticias`: scraping con rotación de UA, paginación y clasificación.
- `GestorDatos`: carga, migra, fusiona, analiza y exporta incidentes.
- `Analitica`: series temporales, pronóstico, hotspots, red, Sankey e indicadores.
- `emit()`: bus de eventos compartido entre terminal y panel web.

git clone https://github.com/Condor2026/Diabolic_Latam
cd Diabolic_Latam
pip install flask requests beautifulsoup4

pip install matplotlib networkx

```bash
chmod +x install.sh

```

```bash
python Diabolic_Latam.py                  # menú interactivo
python Diabolic_Latam.py --web --lang es  # panel web en http://localhost:5013
python Diabolic_Latam.py --web --auto 30  # panel + scan automático cada 30 min
python Diabolic_Latam.py --scan all       # scan completo por CLI
python Diabolic_Latam.py --scan fd        # solo narco y violencia
python Diabolic_Latam.py --scan cyber     # solo finanzas ilícitas
python Diabolic_Latam.py --scan gov       # solo alertas oficiales
python Diabolic_Latam.py --sens amplio    # sensibilidad del filtro
python Diabolic_Latam.py --robots         # respetar robots.txt
python Diabolic_Latam.py --host 0.0.0.0 --port 5013  # exponer en red local
```

## 🧠 Motor de clasificación

Cada titular se evalúa en varios pasos:

1. **Scrub** de usos no criminales (cartel de cine, banda de música, masa de pan, tiros libres, drogas legales, minas de oro…).
2. **Tipos con fuerza variable**:
   - **Fuertes** (basta una coincidencia): narcotráfico, sicariato, masacre, cártel, motín, cobro de piso, etc.
   - **Débiles** (exigen indicio policial/judicial): homicidio, extorsión, secuestro, desaparición, balacera, etc.
3. **Contexto**: presencia de términos policiales/judiciales, exclusión de noticias fuera de LatAm, filtros de deporte/cultura/accidente/lifestyle/navegación.
4. **Confianza** por evento (0–100) según coincidencias, título, contexto, geo precisa y penalizaciones.
5. **Severidad** (1–10) modificada por muertos, heridos, armas de guerra, colectivos vulnerables y cifras.
6. **Conflicto**: marca el evento para alarma si es masacre, terrorismo o violencia armada con severidad ≥ umbral.

Categorías internas:

| Categoría | Contenido |
|---|---|
| `fisico` | Narcotráfico, cárteles, extorsión, secuestro, desapariciones, tráfico de armas, economías ilícitas, homicidio. |
| `rue` | Sicariato, masacre, balacera, narcobloqueo, ataque a fuerzas de seguridad, motín/fuga, terrorismo (disparan la alarma). |
| `cyber` | Lavado de activos, corrupción/narcopolítica (finanzas ilícitas). |

## 🔔 Sistema de alarma

Se dispara cuando:

- Se detecta un evento con `conflicto == True` (masacre, atentado explosivo o violencia armada ≥ umbral).
- Se detectan **≥ 3 eventos de violencia armada en 24 h en el mismo país** (cluster).

En la **consola** imprime una línea en fondo rojo con campana (`\a`). En el **panel web**:

- Banner superior con el/los titulares implicados y botón "Ver en el mapa".
- Sirena configurable (`siren`, `pulse`, `klaxon`) con volumen ajustable.
- Historial de alarmas.
- Notificaciones del navegador (opcional).
- Armado/desarmado/mute temporal.

**Umbral** ajustable (`5`–`9`, por defecto `6`) desde el panel o la API.

## 📈 Analítica e indicadores

- **Serie diaria** y **z-score** para detectar anomalías.
- **Pronóstico semanal** con suavizado de Holt.
- **Palabras en tendencia** (últimas 2 semanas frente a las 8 anteriores).
- **Hotspots** por celda geográfica.
- **Red tipo ↔ país** (networkx / vis-network).
- **Sankey** categoría → tipo → país.
- **Indicadores tipo crypto**:
  - **RSI** de Wilder (14 días).
  - **SMA7 / SMA30** y **momentum**.
  - **Bandas de Bollinger** (±2σ).
  - **Volatilidad** del flujo diario.
  - **Índice de amenaza** 0–100 con niveles: `CALMA`, `VIGILANCIA`, `TENSO`, `CRÍTICO`.
- **Tickers** con sparklines para categorías, tipos principales, RSI, severidad y totales.

### Auto-descubrimiento
Cuando una fuente cambia de dominio, subdominio o sección, el motor:

1. Prueba variantes (`www.`/sin `www`, con/sin barra final).
2. Inspecciona los enlaces de la portada y puntúa por palabras clave (`policiales`, `judicial`, `noticias`, `prensa`, `alertas`…).
3. Prueba rutas clásicas (`/policiales`, `/sucesos`, `/noticias`…).
4. Detecta el RSS de la página si existe.

Todo con **timeout por fuente** (90 s) para que ninguna fuente bloquee el escaneo completo.

## 🧠 Tipo de OSINT y metodología

DIABOLIC se clasifica como **OSINT pasivo y analítico**:

- **Pasivo**: no interactúa con los sistemas de las fuentes más allá de las peticiones HTTP que haría un usuario normal. No realiza inyecciones, no vulnera accesos, no utiliza credenciales.
- **Analítico**: no se limita a recopilar información; procesa los datos para extraer **patrones geográficos (países, estados, ciudades), temporales (evolución diaria, mensual) y relacionales (conexiones entre incidentes)**.

### Flujo de trabajo
1. **Adquisición**: se descargan las páginas de cada fuente respetando tiempos de espera, user-agents y, opcionalmente, `robots.txt`.
2. **Parseo**: se extraen titulares, fechas y se detecta la ubicación (ciudad → estado → país).
3. **Clasificación**: se etiqueta cada incidente con tipo, categoría, severidad y confianza.
4. **Almacenamiento**: se guardan los metadatos en un archivo JSON local, sin datos personales.
5. **Fusión**: se combinan fuentes que cubren el mismo hecho y se refuerza la confianza.
6. **Análisis**: se generan estadísticas, patrones temporales y conexiones.
7. **Visualización**: se muestran los resultados en terminal o web.

### Detección de conexiones
- Agrupa incidentes por **tipo + país** en los últimos 30 días.
- Si hay **3 o más** incidentes del mismo tipo en el mismo país, los muestra como patrón y calcula la frecuencia (incidentes/día).
- Busca palabras clave de modus operandi (`sicariato`, `halcón`, `pitufeo`, `vuelco`…) y agrupa incidentes que compartan la misma técnica.
- Detecta clusters de violencia armada en 24 h para disparar la alarma.

## ⚖️ Ética, legalidad y protección de datos

### Cumplimiento normativo
- **RGPD / LGPD (Brasil) / LOPDGDD**: DIABOLIC no trata datos personales. Solo almacena metadatos (titular, fecha, país, tipo, fuente). Queda fuera del ámbito de aplicación de estas leyes.
- **Propiedad intelectual**: no republica el contenido íntegro de las noticias; solo extrae titulares y metadatos. Las peticiones son las mismas que haría un lector humano, respetando `robots.txt` (opcional) y rate limiting.

### Principios éticos
- **Transparencia**: código abierto, cualquier persona puede auditar qué hace y qué guarda.
- **No vigilancia**: no perfila personas ni almacena información que pueda identificar a individuos.
- **Responsabilidad**: el usuario es el único responsable del uso que dé a la herramienta. El banner de inicio incluye la advertencia y la filosofía Spiderman.

### Exención de responsabilidad
La herramienta se proporciona "tal cual", sin garantías de funcionamiento ininterrumpido. Cualquier modificación que introduzca funcionalidades lesivas (recogida de datos personales, vigilancia encubierta) es responsabilidad exclusiva de quien la realice.
